# 🏫 Class Match (클래스 매치) - 학교 학급 보강 매칭 시스템

> **시험 기간 전 특정 학급의 보강이 필요한 교사와, 해당 학급의 수업을 빌려줄 수 있는 교사를 연결해 주는 Google Apps Script(GAS) 웹 애플리케이션**

---

## 🌟 핵심 기능 및 동작 방식 (Key Features & Workflow)

### 1. 보강 필요 교사의 등록 항목
보강이 필요한 교사가 다음 형식으로 입력하여 등록합니다:
- **희망 학급**: 복수 선택 가능 (학년 및 반 다중 선택 지원)
- **교과명**: 텍스트 창에 직접 입력 (예: `수학`, `영어`)
- **교사명**: 텍스트 창에 직접 입력 (예: `김수학`)
- **내선번호**: 텍스트 창에 직접 입력 (예: `302`)
- **총 희망 차수**: 1~10차시 드랍다운 메뉴로 선택
- **가능 요일 및 각 요일 별 가능 교시**: 월, 화, 수, 목, 금 요일별로 1교시~7교시 버튼을 토글하여 다중 선택할 수 있는 스마트 스케줄 매트릭스 UI 탑재 (예: `월(3, 5교시) | 수(2교시) | 금(4교시)` 형태로 자동 포맷팅)
- **비고/메모**: 시험 범위 또는 진도 안내 텍스트 입력
- **게시 마감일**: 필수 달력 입력 항목으로 지정된 마감일이 지나면 테이블 목록에서 자동으로 숨김 처리됩니다.

### 2. 학급마다 하나의 행으로 직관적인 테이블 표시 및 정렬
- 총 희망 차수가 3차시여도 하나의 학급이면 테이블 및 Google Sheets에 **학급마다 1개의 행**으로 깔끔하게 표시됩니다.
- 복수의 학급(예: 2학년 3반, 2학년 4반)을 선택하여 등록하면 각 학급별로 1행씩 등록됩니다.
- **안내 메세지 배너 & 구글 시트 연동**: 웹앱 최상단에 파스텔 노란색 계열의 안내 배너가 표시되며, 구글 스프레드시트 '안내메세지' 시트의 A1 셀과 실시간 동기화됩니다. 텍스트 길이에 맞춰 박스 너비가 동적으로 조절되고 중앙 정렬됩니다.
- **희망 학급 정렬**: 테이블 헤더의 '희망 학급'을 클릭하여 학년/반 기준 오름차순/내림차순 토글 정렬이 가능합니다.
- **게시 마감일 D-day 시각화**: 테이블에 게시 마감일 열이 제공되어 `D-n`, `오늘 마감`, `내일 마감` 뱃지를 통해 마감 일정을 직관적으로 파악할 수 있습니다.
- **총 희망 차수 인라인 스텝퍼**: 테이블 내에서 `+` / `-` 버튼으로 모달 이동 없이 총 차수를 1~10차시 범위 내에서 즉시 조절할 수 있습니다.
- **미니 시간표 매트릭스 시각화**: '보강 가능한 요일과 교시'를 월~금 x 1~7교시 5x7 미니 시간표 형태로 시각화하여 가능 시간을 직관적으로 확인할 수 있습니다.
- **초고속 웹앱 초기 로딩 (SSR & CacheService)**: 서버 사이드 사전 렌더링(SSR) 데이터 주입 및 Apps Script 인메모리 캐싱을 통해 2차 네트워크 비동기 지연 없이 웹앱 접속 즉시(0.05초) 테이블과 안내 배너가 표출됩니다.

### 3. 보강 희망 수정 및 삭제 기능
- **수정 버튼 (스카이블루 스퀘어)**: 테이블 행의 `[✏️]` 버튼을 클릭하여 총 희망 차수, 가능 요일/교시, 내선번호, 게시 마감일, 비고/메모 등을 간편하게 수정할 수 있습니다.
- **삭제 버튼 (연분홍 스퀘어)**: 테이블 행의 `[🗑️]` 버튼을 클릭하여 확인 후 해당 보강 희망 내역을 완전히 삭제할 수 있습니다.

### 4. 개별 연락 및 매칭 성사 확인 워크플로우
1. **수업 대여 가능 교사**:
   - 테이블에서 학급, 과목, 총 차수, 게시 마감일, 가능 요일/교시, 내선번호를 확인
   - [📞 내선번호]를 확인하여 보강 희망 교사에게 개별 연락
2. **보강을 올렸던 교사**:
   - 동료 교사와 수업 교환 협의가 완료되면, 해당 학급 행의 **`[🤝 매칭 완료]`** 버튼을 클릭하여 원클릭으로 매칭 확정

## 🚀 Google Apps Script 배포 방법 (Deployment Guide)

1. [Google Apps Script 콘솔](https://script.google.com/) 접속 후 새 프로젝트 생성
2. 좌측 파일 목록에 다음 파일들을 복사하여 붙여넣기:
   - `Code.gs`
   - `Index.html` (파일 추가 [+] -> HTML 선택 후 이름으로 `Index` 또는 `index` 입력 후 내용 붙여넣기)
   - `appsscript.json` (프로젝트 설정 -> "appsscript.json 매니페스트 파일 표시" 체크 후 수정)
3. 우측 상단 **[배포]** -> **[새 배포]** 클릭
4. 유형 선택: **웹 앱(Web App)**
   - 설명: `Class Match v1.4 (초고속 로딩 최적화)`
   - 다음 사용자로 실행: `나(내 계정)`
   - 액세스 권한이 있는 사용자: `모든 사용자(Anyone)` 또는 `조직 내 사용자`
5. **[배포]** 버튼 클릭 후 생성된 **웹 앱 URL**을 교사들과 공유하여 사용
